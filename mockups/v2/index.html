data devtools v2 working prototype

New shell powered by real $.graph / $.trace / $.profile / $.inspect. Hold Alt for inline badges. Click any graph node on the right to open the inspector. The dock is anchored to the right edge — no drag, no tab strip. Existing panel suppressed via ?nopanel.

under the hood

  • items = $({...}) — the reactive root every panel pane reads from.
  • active = items.filter('completed', false).length()
  • done = items.filter('completed', true).length()
  • Each <li> binds to items[id] via render() — sinks attach __ripple_sink on the host element, which the Alt-hover overlay walks to.
