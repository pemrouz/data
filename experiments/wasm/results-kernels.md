# Layer 1 — kernel microbench (node v25.9.0)

Generated by `experiments/wasm/bench-kernels.ts`. Median of 9 runs after 3 warmups; inner-loop count auto-calibrated to ≥1ms per measurement.

Metric: ns per element. Lower is better. WASM "wins" only when it beats `js-typed` (the ceiling JS can reach with already-columnar data).
