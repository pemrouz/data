**a · two engines, one delta (PICKED — REAL).** Two engines run in the visitor's tab. `here = $({ t1…t6 })` lives on the page's default runtime; `there = handleFor(new InMemoryBacking(rtB, {}).source)` lives on a second `new api.Runtime()` and is seeded by nothing but the wire: `wireSink(here, cross, { origin: fromWire })` emits the seq-0 snapshot when the card first scrolls into view, `wireSink(there, cross, { origin: fromWire, initial: false })` covers the way back. `cross()` = the seam: the WireBatch is serialised to JSON bytes (TextEncoder), parsed back, printed verbatim in the middle column, the dot rides the hairline, and after a hold (350 ms so the eye can follow — labelled "held N ms for the eye", the N measured) `ingest(other, wb.records, { origin: fromWire })` applies it as ONE commit on the far runtime. Echo suppression is the kernel's (kernel/runtime.ts effect loop: an entry whose declared origin equals the batch's origin is skipped), verified by the seam's own counters. Both tables render from their runtime's own `sink({ init, apply })` — rows are created from the init snapshot / `add` deltas, the qty cell flashes when that side's sink applies an `update`. Clicking or Enter on a row issues a real write on that side (`here.get(k).set('qty', v)` / `there.get(k).set('qty', v)`; two-row writes go through `batch(() => {…})` / `rtB.batch(() => {…})` → one WireBatch with two records). `conform(here[node])` and `conform(there[node])` (conformance/harness.ts: LegalityChecker + ReplaySink on every commit) are attached at construction; a violation would throw through clause 4 out of the write/ingest and print as `✗ …` in the fold line.
**What is real (tier).** runtime: every table cell (key/qty/px from the sink's rows), `rows N` (rowCount()), the printed WireBatch (keyDomain/seq/records — fields of the real object, the pre is stamped runtime), `crossed N` (landings), `echoed back N` (wireSink callbacks that fire during an ingest — the contract holds it at 0), the feet's values (`set('qty', <v>)` read back from the record the engine emitted; `applied N · rejected N` from the IngestReport), the status seq (the batch's seq) and identical/diverged. measured: bytes on the wire (TextEncoder), the hold (performance.now around the setTimeout), and the cost of the landing SPLIT IN TWO — `ingest N ms` is performance.now around `ingest()` MINUS the time this page's own sink spent inside that call (the effect phase runs the table sink synchronously: `mkRow`/`fill`, the flash's forced reflow, the echo ring's `animate`), and `this page's sink N ms` is that subtracted part, timed at the sink's `apply` entry/exit while an ingest is open. The engine side still includes the conform harness (LegalityChecker + ReplaySink on the landing node), so it overstates the engine, never understates it; below the 100 µs clamp of a non-isolated tab's performance.now it prints `<0.1`.
