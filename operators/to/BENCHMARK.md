(mobx/vue/rxjs/svelte), beats preact-signals and solid by 30x+ on batch.

## Known: small gap vs mobx/vue on single

mobx and vue's reactivity tracks dependencies at field granularity — a
BU2 (deep update on one row's `val`) doesn't invalidate
`computed(rows.length)` at all, so the fn doesn't re-run. data's `to`
runs `fn` on every BU2 even when the result is reference-equal (the
`===` check in [index.ts](index.ts) skips downstream notification but
not the fn call). A safe skip would require knowing `fn` only reads
shape (not values) — that's a hint the API doesn't currently provide.
For `to(rows => rows.length)` the fn is O(1) so the gap stays small.

Run `BENCH_OPS=to npm run bench:ops` to refresh.
