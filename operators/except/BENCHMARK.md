# except — benchmark

Workload: 10_000 rows; `filter(active).except(filter(val > 50))`. Tick
mutates either `active` or `val`. Batch streams 1000 such ticks.
Generated by [comparisons/bench/operators/except.bench.ts](../../comparisons/bench/operators/except.bench.ts).

| Library | Setup (ms) | Single (ms) | Batch 1000 (ms) |
|---|---:|---:|---:|
| **data** | 2.12 | **0.080** | **2.18** |
| svelte-store | 1.30 | 0.491 | 520.56 |
| rxjs | 1.38 | 0.509 | 565.21 |
| react | 1.54 | 0.527 | 452.22 |
| preact-signals | 2.55 | 0.816 | 18.69 |
| solid | 8.14 | 3.37 | 68.94 |
| mobx | 106.5 | 9.50 | 198.07 |
| vue-reactivity | 29.34 | 20.53 | 615.07 |

crossfilter omitted — no native set-difference primitive.

data is fastest on both single (6.1x over svelte-store) and batch (8.6x
over preact-signals).

## How

Same bitmask machinery as `intersect`/`union`, set-difference flavour
(operators/except/index.ts).

Run `BENCH_OPS=except npm run bench:ops` to refresh.
