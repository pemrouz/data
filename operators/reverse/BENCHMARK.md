## How

[index.ts](index.ts) maintains a single output array. BI0 (insert at a
fresh key) prepends the new value(s) — incremental, no rebuild. Removes
and updates still rebuild because reverse-mapping a value to its position
is O(N) and ambiguous for duplicate values; that's the right trade-off
for the common workload (streaming inserts).

Run `BENCH_OPS=reverse npm run bench:ops` to refresh — update this file
when the numbers change materially.
